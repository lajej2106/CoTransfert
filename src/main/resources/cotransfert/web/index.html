Clavier et souris partagés

Réglages

1Rôle de ce poste

Il faut un poste de chaque sorte. Si vos deux postes peuvent accepter une connexion, choisissez librement lequel est le hub.

2Dossiers à synchroniser

Choisissez le dossier de ce poste, puis donnez-lui un nom. Le nom doit être exactement le même sur les deux postes : c'est lui qui relie les deux dossiers. L'emplacement, lui, peut être différent d'un poste à l'autre.

Retirer un dossier de cette liste ne supprime aucun fichier.
3Secret partagé

Le secret est un mot de passe commun aux deux postes : il chiffre les échanges et garantit que c'est bien votre autre poste qui répond. Il doit être exactement le même sur les deux postes. Avec le câble seul, il est facultatif ; il devient obligatoire dès que les données sortent du câble (réseau local, WebDAV, Drime) et il est conseillé avec un disque relais.

À la place du câble, vos fichiers peuvent transiter par un espace de stockage en ligne, ou par un disque que vous portez d'un poste à l'autre. Ce qui transite est chiffré par le secret, puis effacé une fois lu. Le câble (« Lien direct ») n'a rien à régler ici.

Régler un canal ne le choisit pas : après l'enregistrement, choisissez-le sur la page principale, dans « Canal de transfert ». Les deux postes doivent avoir les mêmes valeurs (même compte, même dossier).

WebDAV

Un espace de stockage en ligne compatible WebDAV (par exemple un Nextcloud). Préférez un mot de passe d'application, que vous pourrez révoquer, au mot de passe du compte.

Drime

Le service de stockage en ligne Drime. Le jeton personnel se crée dans les réglages de votre compte Drime.

Disque relais

Un disque ou une clé USB que vous branchez tour à tour sur chaque poste (ou un dossier partagé). Créez-y vous-même le dossier : CoTransfert ne le crée jamais. Le premier trajet part du client : branchez le disque d'abord sur le client, puis portez-le au hub.

Pour une clé USB, écrivez *:\CoTransfertRelais : l'étoile retrouve le dossier quelle que soit la lettre du lecteur.

En cas de conflit

Il y a conflit quand un même fichier a été modifié sur les deux postes avant d'avoir pu être synchronisé.

Trouver le hub

Utile sur le client seulement. Normalement, il trouve le hub tout seul par le câble.

Laissez vide pour la recherche automatique. Sinon, le nom ou l'adresse IP du hub.

Sur le réseau local, le secret est obligatoire.

Connexion à Internet

Ne concerne que WebDAV et Drime.

Choisissez « Windows » si votre organisation contrôle les connexions sécurisées avec ses propres certificats.

Clavier et souris partagés

Pilotez l'autre poste avec le clavier et la souris de celui-ci, dans un sens ou dans l'autre. Uniquement par le lien direct, avec le secret partagé, et seulement si la fonction est activée sur les deux postes.

Poussez le pointeur contre ce bord pour passer sur l'autre poste ; là-bas, poussez-le contre le bord opposé pour revenir.

De 0 à 5000 ; 250 évite les passages accidentels.

Ctrl et/ou Alt, Maj facultatif, puis une lettre, un chiffre ou F1 à F12. Préférez une touche de fonction. Vide : pas de raccourci.

Pendant le pilotage, le raccourci clavier rend la main. Pour qu'il serve aussi à partir, ce bouton crée dans le menu Démarrer un raccourci Windows qui porte la touche enregistrée (enregistrez d'abord vos réglages). Sans lui, utilisez le bord de l'écran ou le bouton de la page.

Limites : la même disposition de clavier est nécessaire sur les deux postes ; la touche Windows, Alt+Tab et Ctrl+Alt+Suppr restent sur ce poste et rendent la main ; l'écran de verrouillage et les fenêtres d'autorisation de Windows ne se pilotent pas ; les fichiers et les images copiés ne passent pas d'un poste à l'autre.

Conflits

      
    

    

      
Un conflit, c'est un fichier modifié sur les deux postes avant d'avoir été
        synchronisé. Rien n'a été perdu : CoTransfert n'a rien écrasé, ce poste a gardé sa version et a mis
        celle de l'autre poste de côté, juste à côté. Il reste à choisir, pour chaque fichier, la version à garder.
